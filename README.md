# FormFlow
FormFlow – AI-Powered Document Translation &amp; Summarization Web App

FormFlow is a web application built with HTML, CSS, JavaScript, and Python (Flask) that leverages AI to translate and summarize documents, improving accessibility and readability. Features include text-to-speech in multiple languages and dynamic text zooming, making content more inclusive for diverse users.

Technologies Used: Python, HTML, CSS, JavaScript, Flask, OpenAI API
